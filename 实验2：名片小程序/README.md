# 个人名片小程序（实验2 · 可分享版）

一个以高校教师个人主页风格设计的微信名片小程序：排版简洁正式，使用微信原生分享能力，转发给好友、分享到朋友圈均可真机正常使用。

## 功能亮点

- **高校官网风格排版**：蓝色渐变页头 + 全宽头图 + 基本信息 + 联系方式 + 个人简介 + 荣誉奖项 + 自我评价，蓝白配色、卡片式布局
- **原生分享（真机可用）**：点击页面右上角「···」→「转发给朋友」或「分享到朋友圈」，无需小程序内部按钮
- **一键复制邮箱**：点击邮箱即可复制
- **自定义分享缩略图**：`assets/share.jpg` 为转发时显示的卡片图

## 目录结构

```text
├── app.js / app.json / app.wxss     全局配置与样式
├── config.js                        个人信息配置（改这里即可更新内容）
├── assets/share.jpg                 转发时显示的分享卡片图
├── pages/index/                     首页：名片页面
└── tools/generate-share-image.ps1   重新生成分享卡片图的脚本
```

## 如何修改个人信息

所有个人信息集中在根目录的 [config.js](./config.js)：

- 姓名、学校、学院（信息科学与工程学部）、年级、专业、职务、邮箱
- 个人简介、自我评价
- 分享卡片图底部提示语

修改后重新生成分享卡片图（可选）：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\generate-share-image.ps1
```

## 分享功能说明

本项目不内置分享按钮或分享面板，使用的是微信小程序的**原生分享**：

1. 在微信开发者工具中点击“预览”，用手机微信扫码进行**真机预览**；
2. 在手机上打开小程序后，点击右上角「···」；
3. 选择「转发给朋友」（分享给真实好友/群聊）或「分享到朋友圈」。

说明：

- 开发者工具模拟器里点转发时显示的“模拟群聊”只是工具的测试占位，真机预览时显示的是真实好友和群聊；
- 在 app.json 中已开启 `enableShareAppMessage` 与 `enableShareTimeline`，分享配置无需额外设置；
- 未发布的小程序，分享出去的卡片只有“体验成员”或预览用户能打开；正式发布后任何人都可以打开。

## 注意事项

- 从朋友圈打开的小程序为“单页模式”，只能浏览当前页面；
- 远程头图来自项目原有素材，如需替换，直接修改 `pages/index/index.wxml` 中 `.banner` 图片的 `src` 即可。
