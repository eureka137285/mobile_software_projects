## 一、实验内容

### 一、实验目的

1. 综合运用微信小程序的基础知识，完成一个完整的新闻前端小程序项目，模仿新闻类 App 实现高校新闻网功能。

2. 掌握小程序页面创建、`tabBar`配置、轮播 swiper 组件、页面跳转、数据绑定、本地存储等知识点。

3. 熟练掌握小程序开发者工具的真机预览、调试、控制台排错等开发操作。

4. 实现新闻浏览、新闻收藏、微信用户信息获取、收藏列表读取等业务逻辑，理解模拟数据与页面渲染的配合方式。

### 二、实验步骤

1. **项目创建与初始化**

   1. 打开微信开发者工具，新建小程序项目，选择 JS 基础模板，不使用云服务。

   2. 在`app.json`的 pages 数组中新增`pages/detail/detail`、`pages/my/my`，自动生成新闻详情页与个人中心页面。

   3. 清空`index`、`app`对应的 wxml、wxss、js 文件原有内容，使用模板自动补全`Page()`、`App()`函数。

   4. 下载实验素材压缩包，解压后将`images`图片文件夹、`utils`工具文件夹复制到项目根目录，`common.js`提供模拟新闻数据与获取新闻的工具函数。

2. **全局配置（app\.json）**

   1. 修改`window`配置，设置导航栏背景色`#328EEB`、标题 “我的新闻网”、文字颜色白色。

   2. 配置`tabBar`，设置首页、我的两个切换标签，配置普通与选中状态图标，实现底部标签栏切换页面。

3. **视图页面开发**

   1. **首页 index 页面**：使用`<swiper>`组件实现自动轮播图，设置指示点、自动播放、切换间隔；使用`wx:for`循环渲染新闻列表，每条新闻绑定点击跳转事件，传递新闻 id 参数。将新闻列表公共样式写入全局`app.wxss`，实现样式复用。

   2. **新闻详情 detail 页面**：布局新闻标题、新闻海报图片、新闻正文、发布日期；设置收藏按钮，根据收藏状态切换 “已收藏 / 未收藏”，绑定添加收藏、取消收藏点击事件。注意海报图片样式问题，将图片宽度设置为`700rpx`解决图片无法正常显示的问题。

   3. **个人中心 my 页面**：分为登录模块与收藏列表模块；`wx:if/wx:else`判断登录状态，未登录展示登录按钮，登录后展示微信头像与昵称；登录成功后渲染本地存储的收藏新闻列表，显示收藏数量，收藏项可点击跳转新闻详情。

4. **业务逻辑编写**

   1. 在各页面 js 文件开头引入`var common = require('../../utils/common.js')`，调用工具函数获取模拟新闻数据。

   2. 首页逻辑：页面加载`onLoad`调用`common.getNewList()`获取新闻列表赋值给页面 data；实现`goToDetail`跳转函数，通过`wx.navigateTo`携带 id 跳转到详情页。

   3. 新闻详情页逻辑：页面加载时接收 url 传入的新闻 id，读取本地存储判断新闻是否已经被收藏；未收藏则调用`common.getNewsDetail()`获取新闻内容；实现`addFavorites`添加收藏、`cancelFavorites`取消收藏，使用`wx.setStorageSync`、`wx.removeStorageSync`做本地缓存操作。

   4. 个人中心逻辑：`getUserInfo`调用`wx.getUserProfile`获取用户微信头像昵称，修改登录状态；`getMyFavorites`读取本地全部 storage，遍历 key 得到收藏新闻数组；页面`onShow`生命周期，登录状态下刷新收藏列表；实现收藏新闻点击跳转详情功能。

5. **调试测试**

   1. 使用模拟器、真机预览分别测试全部功能；测试轮播自动播放、新闻跳转、收藏 / 取消收藏、登录、收藏列表刷新等功能。

   2. 控制台查看报错，排查样式、数据绑定、本地存储、页面传参的问题。

## 二、问题总结与体会

### 一、问题总结

1. detail 页面海报图片设置`width:100%`时图片无法显示，参考实验提示修改为`700rpx`后图片正常渲染，推测是容器与图片尺寸单位不匹配导致渲染异常。

2. 个人中心页面切换回来，收藏列表不会自动更新。调试后发现，页面从详情页返回个人中心不会触发 onLoad，需要写在`onShow`生命周期，每次页面显示都重新读取本地收藏数据，刷新列表。

3. 忘记在页面 js 顶部引入`common.js`，调用新闻获取函数时报`undefined`，补充 require 导入语句后恢复正常。

4. 页面跳转传参时，`data-id`绑定写错属性名，导致详情页拿不到 id，仔细核对 wxml 中 data\-\* 属性与 js 读取 dataset 的字段，修复该 bug。

5. 微信用户信息接口，旧接口废弃，使用`wx.getUserProfile`获取用户头像昵称，必须由用户点击按钮触发，不能直接在生命周期自动调用，否则调用失败。

### 二、体会

本次实验完成了高校新闻网小程序完整前端项目，把课程中学到的小程序组件、生命周期、事件绑定、页面路由跳转、本地存储等知识点串联起来，对微信小程序开发流程有了完整的理解。

开发过程中体会到页面生命周期的区别，`onLoad`只执行一次，`onShow`每次页面显示都会执行，适合做数据刷新类逻辑；本地存储适合做简单的收藏功能，不需要后端接口就可以实现数据持久化。同时学会使用开发者工具控制台、Storage 调试面板排查数据问题。

在写视图层代码的时候，要注意 rpx 响应式单位，图片样式容易出现渲染异常，需要多调试样式。同时理解了模拟数据的作用，借助`common.js`模拟后端接口返回数据，完成前端业务开发。

本次实验也暴露出自己细节上容易出错，比如忘记导入 js 模块、绑定事件参数写错字段。后续写代码要更加细心，遇到报错优先看控制台输出，定位问题来源。如果继续优化项目，可以增加下拉刷新、新闻分类、删除收藏等功能，丰富小程序体验。
